# 金钥会 AUREUM

试玩金私人厅堂原型（Play-money demo）。不含真实货币下注，余额保存在本机 `localStorage`。

## 启动

```bash
npm install
npm run dev
```

打开终端提示的本地地址（默认 `http://127.0.0.1:5173`）。

## 功能

- 大厅：分类筛选、日榜、入会占座
- 可玩：老虎机、百家乐、二十一点、欧洲/美式轮盘
- 体育：滚球盘口、注单、本地结算
- 钱包：USDT / 卡 / 银行沙盒充提示意
- 会员：昵称、活动流水、重置演示
- 规则：各玩法速览
- 币种：CNY / MYR / USDT 显示换算
